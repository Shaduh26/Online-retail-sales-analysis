## Project Overview
This project analyzes online retail transaction data using SQL (SQLite) and Tableau.  
The objective was to clean the dataset and explore key business questions related to revenue, customer behavior, and sales trends.

## Dataset
The dataset consists of online retail transactions with the following key fields:

| Column Name   | Description |
|---------------|------------|
| Customer ID   | Unique identifier for each customer |
| Invoice       | Unique transaction identifier |
| Invoice Date  | Date of purchase |
| Quantity      | Number of items purchased |
| Price         | Price per item |
| Country       | Country of the customer |
| Revenue       | Calculated as Quantity × Price |

## Data Cleaning
A cleaned dataset (`retail_clean`) was created to ensure accurate analysis by removing incomplete records:

- Removed rows with missing **Customer ID**
- Removed rows with missing **Description**
- Preserved the original dataset for reference

## Tools Used
- SQL (SQLite)
- Tableau Public
- GitHub

## Key Business Questions
1. Which countries generate the most revenue?
2. Who are the top 10 customers by revenue?
3. How does revenue change over time?


## SQL Analysis

### 1. Total Revenue
Calculated total revenue generated by the business.

### 2. Revenue by Country
Analyzed revenue distribution across countries to identify top-performing markets.

### 3. Top Customers
Identified the top 10 customers based on total spending.

### 4. Sales Trend Over Time
Analyzed daily/monthly revenue trends to identify patterns and seasonality.

## Key Insights
- The **United Kingdom** dominates revenue, generating over $6.7 million.
- Revenue is highly concentrated in a single market, indicating limited geographic diversification.
- The top customer generated approximately $279K, showing reliance on high-value customers.
- Sales trends indicate increased activity toward the end of the year, suggesting seasonal demand.
